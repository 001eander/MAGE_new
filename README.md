# MAGE 实验说明

本文件只写**要做什么、怎样算做完**。安装、论文预训练、官方评测命令见 [README.official.md](README.official.md)。

代码来自论文 [MAGE](https://arxiv.org/abs/2211.09117)。模型不直接画像素，而是预测 256 个编号（词表大小 1024）。这些编号再交给冻结的 VQGAN 解码成图。所以像素上能达到的最好结果，是同一张 256×256 图先编码再解码，不是原始 JPEG。

下面用到的几个词：

- **编号 / token**：VQGAN 给每个 16×16 小块的 codebook 编号，一张图 16×16=256 个。
- **FID**：生成图的分布和参照图差多远，越小越好。
- **遮挡（mask）**：训练或生成时把一部分编号藏起来，让模型去猜。
- **标签平滑（label smoothing）**：算分类损失时不把正确答案看成 100%，默认系数 0.1。

## 2. 训练规模、指标、大 n 泛化



### 2.1 训练集大小 n

数据来源和预处理保持不变，按下面的 n 全部跑完：

```
n = 1, 2, 10, 100, 1000, 10000
```

要求：

- 每个 n 用**固定的一组图**（写清文件列表或随机种子）。比较不同设置时不要换图。
- 更大的 n 必须包含更小 n 的全部图（嵌套）。n=2 的两张固定为半 A 半 B 的 A、B，不要另找两张。
- 结果按 n 分行写，不要只报其中一个 n。

数据：

- n\le 1000 可以用 Tiny-ImageNet 的固定子集，但必须写明：原图是 64×64，训练和评测前放大到 256。这样得到的 FID **不能**和论文在 ImageNet 256×256 上的数字比较。
- 要和论文比 FID（尤其 n=10000 和 `*50000`），必须用 ImageNet 256×256 子集，参照集用官方脚本 `prepare_imgnet_val.py` 做好的验证集。

### 2.2 训练之后必须报告的指标

每个 n、每种设置都要留下下面四样。少一样，这一行就不算做完。


| 指标         | 看什么               | 留什么                              |
| ---------- | ----------------- | -------------------------------- |
| **FID**    | 生成图整体像不像参照集       | `metrics.json` 里的数字，以及比较的两个文件夹路径 |
| **覆盖率**    | 训练集有多少张能在生成结果里被对上 | 定义见下，写入 `metrics.json`           |
| **平均匹配误差** | 生成图离最近的一张训练图有多远   | 编号和像素各报一次                        |
| **图像质量**   | 好不好看、有没有塌成一张图     | 固定拼图，不要只留最好看的一张                  |


怎么算（改算法必须改本文件，并重算所有 n）：

**FID**

- 参照集要和这个 n 用同一类数据。Tiny 子集就对 Tiny 子集（或其 VQGAN 重建、放大后的验证图）；ImageNet-256 就对 `prepare_imgnet_val.py` 的验证集。
- 另外报一档 **VQGAN 重建 FID**：把参照集每张图编码再解码，再和原参照集算 FID。这是量化本身能达到的最好 FID，见第 4.5 节。生成 FID 必须和这一档写在一起。
- 生成张数：小 n 至少 `max(1000, 50n)` 张（有重复要写明）；n \ge 10000 且要和论文对齐时用 50000 张。温度、迭代步数、每步是取最大概率还是随机采样，都写进 `metrics.json`。

**覆盖率**

- 对每张训练图，在生成集合里找编号最接近的一张。接近程度 = 256 个位置里有多少个编号不同。
- **完全覆盖**：最近那张 256 个编号全对的训练图所占比例。
- **大致覆盖**：最近那张至多错 16 个编号（6.25%）的比例。
- 小 n 两种都报。大 n 完全覆盖可以接近 0，大致覆盖和匹配误差仍要报。

**平均匹配误差**

- 编号：生成图和最近训练图有多少比例的位置编号不同（不同的个数 / 256），对所有生成图取平均。
- 像素：这一对图在 VQGAN 解码结果上的均方误差，不要拿未量化的 JPEG 来比。
- 每个 n 都另报一栏：一次揭开全部遮挡时，对训练图猜对了多少编号（「相对自己」）。这和「对最近邻」分开写。大 n 可对固定探测集平均：至少包含 A、B，再从该 n 里固定抽若干张。

**图像质量**

- 每个 n、每种设置一张固定拼图：至少 8 张生成图，加上各自最近的训练图，以及那张训练图的 VQGAN 重建。
- 每个 n 都要能看出是整图复现、几张混在一起，还是只换了局部小块。
- 文件名写入 `metrics.json`，例如 `outputs/<实验名>/n<N>/grid.png`。



### 2.3 n 大时看泛化

在 n=1000 和 n=10000 上必须做；如果训练了 `*50000` 也做。n\le 100 不要据此谈「大集合上的泛化」。

1. **FID**
  生成方式和第 2.2 节相同，看 FID 是否随 n 变小，以及离 VQGAN 重建 FID 还有多远。
2. **加噪声**
  模型训练好之后不再改权重，只改测试输入：
  - 随机改编号：把当前能看见的编号按比例 p = 0, 0.05, 0.1, 0.2, 0.5 换成别的编号。
  - 像素加高斯噪声：在 256×256、像素值 [0,1] 的图上加标准差 \sigma = 0, 0.05, 0.1, 0.2，再编码后生成或补全。
  - 每个 p、每个 \sigma 都报 FID 和平均匹配误差。
  - 目的：看模型学的是稍加扰动还能用的结构，还是把训练编号整张背下来。

## 4. 分类头、遮挡与量化

第 4.1–4.4 节在第 2.1 节每个必须做的 n 上都要做，并报告第 2 节的指标。不要只在小 n 上做完原理、大 n 只复查一眼。结论按 n 写：某个现象是一直都在，还是随 n 变了。

n=1 做不了半 A 半 B（只有一张图），从 n=2 做到最大的必须做的 n。

### 4.1 理论解：分类头 × 标签平滑

每个必须做的 n 都要跑满四种组合。不要只跑「能把图背下来」的那一种，也不要只在 n=1、2 上跑。


| 分类头   | 代码里是什么                            | 按理论，取最大概率时会怎样                                                              |
| ----- | --------------------------------- | -------------------------------------------------------------------------- |
| 点积    | 官方 `MlmLayer`：用隐向量和**不更新**的词向量做点积 | 隐向量被限制在词向量张成的空间里。加上标签平滑后，最优点靠近「正确答案向量和全体平均的混合」，最大概率对应的编号可以是「长得像正确答案的另一个编号」 |
| 独立分类头 | `--linear_head`，一层线性映射到 1024 类    | 没有标签平滑时，可以学成只认正确答案。有标签平滑时，概率会被摊开，但最大概率仍可以是正确答案                             |



| 损失   | 代码                    | 按理论会怎样                                      |
| ---- | --------------------- | ------------------------------------------- |
| 标签平滑 | 默认系数 0.1              | 单独使用时，独立分类头仍可能猜对编号；和点积加在一起，才更容易变成「换一个相近的小块」 |
| 不平滑  | `--label_smoothing 0` | 独立分类头可以精确记住编号                               |


四种组合每一种都要报：

- 一次揭开全部遮挡时，对训练图猜对多少编号
- 猜错的编号，和正确答案在词向量里有多近（余弦距离、欧氏距离），并和随机猜错比较
- 第 2.2 节的 FID、覆盖率、匹配误差、拼图

不要用某一个 n、某一种设置的「编号全对」代替这四种组合。如果某次失败时同时改了分类头、遮挡方式和学习率，不要把它说成只是其中一个原因。四种组合的表按 n 分行，便于看出随训练集变大，精确记住编号和「换相近小块」谁在占上风。

### 4.2 点积 / 标签平滑会不会变成「换相近的小块」

要验证的说法：官方分类头加标签平滑时，模型学的不是「这个位置必须是编号 y」，而是「隐向量靠近 y 附近的一簇词向量」。周围能看见的编号一变，它就换成看起来差不多的另一块。

除了第 4.1 节里「猜错的编号离正确答案有多近」，主要证据是下一节的半 A 半 B。独立分类头、不平滑，应更像整图背下来；点积加标签平滑，应更像局部替换。两种都要跑，只跑一种不算。每个必须做的 n（从 n=2 起）都要有这两边的对比，不能只在小 n 上成立就当结论。

### 4.3 测试时一次揭开多个位置；半 A 半 B

生成时，每一步会对所有还藏着的位置**分别**算概率，这些位置之间不算互相依赖。一次揭开越多，越容易拼出左右对不上的图。

**半 A 半 B（必须做）：**

1. 图像 A、B 固定为 n=2 的那两张，并且出现在所有更大的 n 里。每个必须做的 n（从 n=2 起）都用**该 n 上训好的模型**做同一套拼接，不要只在 n=2 的模型上看。
2. 在编号图（16×16）上拼接，至少两种切法，结果分开写：
  - 左右：左边 8×16 来自 A，右边 8×16 来自 B；
  - 棋盘，或随机各取 128 个位置。
3. 模型能看见的是拼好的编号，要它补被藏住的部分。比较两种揭法：
  - 一步揭开全部未知位置；
  - 一步只揭开 1 个未知位置，重复直到补完。
4. 报告：补出来的编号更像 A、更像 B，还是只在接缝附近换成相近的小块。和「理想拼图」（A 的一侧全是 A，B 的一侧全是 B）比，有多少位置编号不同。图要能看到：可见的拼图、一步全揭、逐步揭开、A、B、以及各自的 VQGAN 重建。

论文默认的 12 步生成会把已经猜对的位置再遮回去。那不是这个实验，不能拿来代替半 A 半 B。

### 4.4 训练和测试的遮挡比例：0–1 对 0.5–1

论文默认训练时，被遮住的比例抽在 [0.5, 1]，并且编码器固定丢掉 50% 的位置。测试生成从「一个编号都看不见」走到「几乎全看得见」。训练时很少见到这两种极端。

比较时只改怎么抽遮挡，分类头和标签平滑跟官方走，或跟第 4.1 节指定的组合走，表上要写清楚：


| 名称      | 训练                                 | 目的                |
| ------- | ---------------------------------- | ----------------- |
| `0.5-1` | 最小遮挡比例 0.5，按论文的截断正态分布抽             | 论文默认，和测试时的遮挡过程对不齐 |
| `0-1`   | 最小遮挡比例 0，可以从全看得见抽到全看不见，也不再固定丢掉 50% | 把测试会遇到的情况都练到      |


测试用同一套办法（一次全揭、论文默认的多步生成、半 A 半 B），比较猜对多少编号、匹配误差、FID。每个必须做的 n 都要比 `0.5-1` 和 `0-1`。不要只在「训练时永远全部遮住」这一种设定上说已经对齐，也不要只在小 n 上比完。

### 4.5 量化误差：FID 和 VQGAN

像素上的上限是 VQGAN 重建，不是原图。论文 FID（ViT-B 11.1，ViT-L 9.10）里，有一部分误差来自 1024 个词、16×16 个位置，模型再准也消不掉。

每个要报 FID 的设置，三个数字写在一起：

1. **VQGAN 能到的最好结果：** 参照集重建 vs 原参照集的 FID
2. **编号全对时的结果：** 若生成编号和参照图完全一样，像素就是重建图，FID 等于上一档
3. **实际生成的 FID：** 模型采样 vs 参照集

(3) 减 (1) 才是分类头、标签平滑、遮挡方式和采样带来的误差；(1) 是 VQGAN 自己的误差。不要只报 (3)。Tiny-ImageNet 放大到 256 之后，(1) 往往会很高，不能据此说「MAGE 很差」，也不能拿去和论文的 11.1 比。
